# AIO Jellyfin: releases

Release builds of **AIO Jellyfin** (`uc-intg-aiojf`), an Unfolded Circle Remote Two / Remote 3 custom integration that shows what your TV is playing (title, series and episode, artwork, progress, and who's watching), from the Jellyfin-compatible server built into AIOMetadata or AIOStreams.

This repository only hosts release archives. The source code is private.

## Install

1. Download the latest `uc-intg-aiojf-v*-aarch64.tar.gz` from [Releases](../../releases).
2. In the Remote's Web Configurator, go to **Settings → Integrations & Docks → Custom Integrations → Upload** and select the archive.
3. Add the integration and follow the setup. Start playing something on your TV before choosing the device.

After the first install, the [Integration Manager](https://github.com/JackJPowell/uc-intg-manager) detects new releases here and can update the integration for you.
